# Installation

## Stable release

To install JEV_Expirements, run this command in your terminal:

```sh
uv add python-boilerplate
```

Or if you prefer to use `pip`:

```sh
pip install python-boilerplate
```

## From source

The source files for JEV_Expirements can be downloaded from the [Github repo](https://github.com/KaRtHiK-56/python_boilerplate).

You can either clone the public repository:

```sh
git clone https://github.com/KaRtHiK-56/python_boilerplate
```

Or download the [tarball](https://github.com/KaRtHiK-56/python_boilerplate/tarball/main):

```sh
curl -OJL https://github.com/KaRtHiK-56/python_boilerplate/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd python_boilerplate
uv sync
```
